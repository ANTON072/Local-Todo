# LocalTodo アーキテクチャ

何を作るかは [PRD.md](PRD.md) を参照。この文書は、それをどう作るかをまとめる。

## 1. 技術の選択

| 項目 | 選択 | 理由 |
|---|---|---|
| 形態 | macOS ネイティブアプリ（SwiftUI。必要な部分だけ AppKit） | 起動も操作も最速。Electron などの重さがない |
| ビルド | Xcode プロジェクト（XcodeGen の `project.yml` から生成） | Info.plist・アイコン・署名・プレビューを標準の形で扱える。`.xcodeproj` を手で書かず、設定をテキストで管理できる |
| 対応 OS | macOS 14 以上 | `@Observable` などの新しい SwiftUI の API を使うため |
| 言語 | 日本語のみ。ローカライズの仕組みは使わず、文字列を直接書く | 日本語環境だけで使うため |
| 外部ライブラリ | 使わない | 標準の SwiftUI・AppKit・Foundation・LinkPresentation で足りる |
| 外部通信 | URL のページタイトルを取得するときだけ | データは Mac の外に出さない |

## 2. データモデル

- タグは `#` を付けずに保存し、重複させない。
- タグ専用のデータは持たない。タグの一覧と件数は、全 Todo から集計する。
- タグの同一判定は、英字の大文字・小文字を区別しない比較で行う。保存するときは、既にある書き方にそろえる。

### 2.1 期限の判定

- 日付が変わったことは `NSCalendarDayChanged` の通知で知り、並び直す。時刻つきの期限超過は、次の期限時刻にタイマーを仕掛けて表示を更新する。

## 3. 保存

### 3.1 Todo のデータ

- 起動時に全件を読み込み、以降はメモリ上のデータを正とする。

### 3.2 画面の状態

`UserDefaults`（`@AppStorage`）に次のものを保存する。

- 選んでいた画面（Inbox／アーカイブ）
- 並び順
- Inbox のフィルタと、アーカイブのフィルタ（別々に保存）
- 詳細ペインの表示／非表示

ウィンドウの位置と大きさは、SwiftUI の標準の復元に任せる。

## 4. 構成

```
┌──────────────────────── Views（SwiftUI） ────────────────────────┐
│ SidebarView   TodoListView / TodoRowView   TodoDetailView        │
│ TaggedTextField（AppKit）   TagEditor                             │
└───────────────┬──────────────────────────────────────────────────┘
                │ 表示用の一覧を読む／操作を呼ぶ
┌───────────────▼──────────────────────────────────────────────────┐
│ TodoStore（@Observable）                                          │
│ ・全 Todo の保持、追加・編集・完了・削除                            │
│ ・フィルタ・並び順・見出しの計算                                    │
│ ・UndoManager への登録、約3秒の猶予の管理                           │
└──────┬──────────────────────┬───────────────────────┬─────────────┘
       │                      │                       │
┌──────▼───────┐   ┌──────────▼─────────┐   ┌─────────▼──────────┐
│ Persistence  │   │ TagParser          │   │ LinkTitleFetcher   │
│ JSON 読み書き │   │ #タグ の抽出        │   │ URL 判定とタイトル取得│
└──────────────┘   └────────────────────┘   └────────────────────┘
```

- 状態を持つのは `TodoStore` だけにする。ビューは `TodoStore` から表示用の一覧を受け取り、操作を `TodoStore` のメソッドとして呼ぶ。
- `TagParser` と `LinkTitleFetcher` の URL 判定は、状態を持たない関数として作り、単体テストしやすくする。

## 5. 主な処理

### 5.1 一覧の計算

- 全件をメモリに持ち、フィルタ → 並び替え → 見出しへの振り分けを、表示のたびにメモリ上で計算する。数千件なら一瞬で終わる。
- 「フィルタ対象外」の一時表示：選択中の Todo の ID を `TodoStore` が覚えておき、条件に合わなくても一覧に含める。選択が外れたら、その ID を外す。

### 5.2 完了・戻すの約3秒の猶予

- チェックされた Todo の ID を「保留中」として覚え、見た目だけを完了（または未完了）にする。
- 最後のチェックから約3秒たったら、保留中のものをまとめて `completedAt` を更新し、一覧から移す。続けて完了にした行がまとめて消えるのはこのため。
- 猶予の間にもう一度クリックされたら、保留から外す。
- 保留中にアプリが終了したときは、保留中の変更を確定してから保存する。

### 5.3 取り消し（⌘Z）

- `UndoManager` を使う。`TodoStore` の変更操作ごとに、元に戻す操作を登録する。
- 完全削除は登録しない（取り消せない操作として扱う）。
- 文字入力中の ⌘Z は、入力欄の標準の取り消しに任せる。

### 5.4 タグの抽出（TagParser）

1. 先に `NSDataDetector` で URL の範囲を見つけ、その中の `#` は対象から外す。
2. 残りの文字列から、`#` か `＃` で始まり、直前が文頭か空白のものを探す。空白（半角・全角）・改行・文末までをタグ名とする。
3. タグ名と、タイトルから取り除いた残りの文字列を返す。

### 5.5 タグ付きの入力欄（TaggedTextField）

- SwiftUI の `TextField` では文字の一部に色を付けられないので、`NSTextView` を `NSViewRepresentable` で包んで作る。
- 入力のたびに `TagParser` で `#タグ` の範囲を求め、アクセントカラーを付ける。
- `#` を打ったら、カーソル位置の近くに候補のポップアップを出す。↑↓・Tab・Enter はポップアップが開いている間だけ候補の操作に使う。
- ⌘Enter で確定を通知する。Enter だけのときは何もしない（改行も入れない）。
- タイトル欄と、詳細ペインのタグ欄の両方でこの部品を使う。

### 5.6 URL のタイトル取得（LinkTitleFetcher）

- URL の判定には `NSDataDetector` を使う。
- タイトルの取得には `LinkPresentation` の `LPMetadataProvider` を使う。取得は非同期で行い、画面の操作を止めない。
- 取得を待つ間にユーザーがタイトルを書き換えていたら、取得結果で上書きしない。
- 取得できなかったとき：タイトルのリンクはドメイン名、追加リンクは「ドメイン名＋URL の末尾」にする。
- 時間がかかりすぎるとき（10秒）は打ち切る。

## 7. ビルドと配布

- `project.yml` から `xcodegen generate` で `LocalTodo.xcodeproj` を作る。`.xcodeproj` は生成物として扱う。
- App Sandbox を有効にし、権限は「外向き通信」（ページタイトルの取得用）だけ付ける。
- 署名は「Sign to Run Locally」（Apple ID は要らない）。
- `scripts/install.sh` で Release ビルドし、`/Applications/LocalTodo.app` に置く。

## 8. テスト

単体テスト（XCTest）の対象：

- 期限超過と見出しの振り分け（日付だけ／時刻つき、0:00 の境目）
- 並び順（同じ日の時刻つきと日付だけの順）
- フィルタ（タグの AND、期限の範囲の OR、キーワード、組み合わせ、「フィルタ対象外」の一時表示）
- タグの抽出（全角 `＃`、`C#`、URL 内の `#`、大文字・小文字）
- URL の抽出（タイトル全体が URL、一部が URL）
- タグの名前の変更・統合・削除
- 約3秒の猶予（まとめて確定、途中での取り消し）
- 保存と読み込み（往復で内容が変わらないこと、バックアップの作成）

画面の動きは、各実装ステップの終わりにアプリを起動して確かめる。

## 9. 実装ステップ

0. **準備（ユーザー作業）**：App Store から Xcode を入れて一度起動し、追加コンポーネントの導入と利用規約への同意を済ませる。続けて `sudo xcode-select -s /Applications/Xcode.app` を実行する。
1. **土台**：`brew install xcodegen`、`project.yml`、Todo モデル、TodoStore と JSON の読み書き、`AccentColor` の登録。空のウィンドウが起動するところまで。
2. **基本機能**：3列の画面、新規追加（⌘Enter）、詳細ペインでの編集、完了とアーカイブ、アーカイブから戻す、約3秒の猶予、Inbox での削除、取り消し。
3. **アーカイブの完全削除**：複数選択、1件・まとめて・全件の完全削除、確認ダイアログ。
4. **期限**：日付ピッカーと時刻のトグル、「今日」ボタン、期限超過と今日の強調、期限日順の見出し、期限切れバッジ、日付が変わったときの更新。
5. **並び順とフィルタ**：期限日順・作成日順の切り替え、フィルタ（タグ・期限の範囲・キーワード）、「フィルタ対象外」の一時表示、状態の保存と復元。
6. **タグ**：TagParser、タグ付きの入力欄（強調と候補）、タイトルからの抽出、タグ欄、サイドバーの集計、名前の変更と削除。
7. **リンク**：タイトルのリンク、URL の自動リンク化とタイトル取得、追加リンク。
8. **仕上げ**：キーボード操作、空の状態とアニメーション、ライト・ダーク両方での見た目の確認、単体テストの拡充、アプリアイコン、`/Applications` への配置。
