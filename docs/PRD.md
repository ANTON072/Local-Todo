# LocalTodo PRD（プロダクト要求仕様）

実装の方式は [ARCHITECTURE.md](ARCHITECTURE.md) を参照。

## 1. 概要

自分の Mac の中だけで動く、シンプルな Todo アプリ。

- 利用者は自分1人。データは Mac の外に出さず、共有もしない。
- UI は日本語のみ。
- 一番大事にするのは「きびきび動く」こと。思いついたらすぐ書け、すぐ消せる。
- リストは Inbox 1つだけ。完了した Todo はアーカイブに移る。

## 2. 用語

| 用語 | 意味 |
|---|---|
| Todo | 1件のやること。タイトル・期限日・タグ・リンク・ディスクリプションを持つ |
| Inbox | アーカイブ以外のすべての Todo |
| アーカイブ | 完了にした Todo の置き場。チェックを外せば Inbox に戻る |
| 完全削除 | アーカイブから Todo を消すこと。元に戻せない |
| タグ | Todo の分類。1件に複数付けられる。`#仕事` のように書く |
| タイトルのリンク | タイトルに結び付いた URL。あればタイトルがリンクになる |
| 追加リンク | タイトルとは別に持つ URL。複数持てる |
| 期限切れ | 期限日が昨日以前の Todo |
| 期限超過 | 期限を過ぎた Todo。時刻つきは時刻を過ぎたとき、日付だけはその日が終わったとき |

## 3. Todo が持つ情報

| 項目 | 必須 | 内容 |
|---|---|---|
| タイトル | ○ | `#タグ` は含まない |
| タイトルのリンク | | URL 1つ |
| 期限日 | | 日付。時刻は任意 |
| タグ | | 複数。重複なし |
| 追加リンク | | 複数。URL と表示名の組 |
| ディスクリプション | | プレーンテキスト |
| 作成日時 | ○ | 自動で記録 |
| 完了日時 | | 完了したときに記録。これがあればアーカイブ |

## 4. 画面

```
┌────────────┬──────────────────────────────┬───────────────┐
│ サイドバー  │ リスト                         │ 詳細（編集）   │
│            │ [＋ 企画書を送る #仕事 ……]      │               │
│ 📥 Inbox 5 ❶│ フィルタ: [#仕事 ×][今週 ×] 並び順▾│ タイトル       │
│ 🗄 アーカイブ│ ── 期限切れ ──                  │ タイトルのリンク│
│            │ ☐ 企画書を送る  #仕事  11/24 ⚠ │ 期限日 [時刻☐]  │
│ タグ        │ ── 今日 ──                      │ タグ #a #b     │
│  #仕事  3  │ ☐ 見積確認      #仕事  15:00    │ リンク（複数）  │
│  #読書  1  │ ── 明日以降 ──                  │ ディスクリプション│
│            │ ☐ 本を読む     #読書  12/01     │               │
│            │ ── 期限なし ──                  │               │
│            │ ☐ Apple - 公式  #調べ物          │               │
└────────────┴──────────────────────────────┴───────────────┘
```

### 4.1 ウィンドウ

- サイドバー・リスト・詳細ペインの3列構成。
- ウィンドウは1つだけ。閉じるとアプリも終了する。
- 次回起動時は、ウィンドウの位置と大きさ、選んでいた画面（Inbox／アーカイブ）、フィルタ、並び順を復元する。

### 4.2 サイドバー

- Inbox、アーカイブ、タグ一覧を並べ、それぞれ件数を出す。
- 期限切れが1件以上あるときは、Inbox の横に件数を赤バッジで出す。
- タグは複数選べ、選んだタグがフィルタになる（→ 5章）。

### 4.3 Inbox のリスト

**追加**
- リスト上部の入力欄でタイトルを打ち、⌘Enter で追加する。
- Enter だけでは追加しない。日本語入力の変換確定で誤って登録されないようにするため。
- `#タグ` と URL も同じ欄に書ける（→ 6章・7章）。

**並び順**
- 「期限日順」と「作成日順（新しい順）」を切り替えられる。選んだ並び順は次回起動時も保つ。
- 期限日順：
  - 期限なしの Todo は末尾。
  - 同じ日が期限のものは、時刻つきを時刻の早い順に先に並べ、日付だけのものを後ろに作成日の古い順で並べる。
  - 「期限切れ」「今日」「明日以降」「期限なし」の見出しで区切る。
  - 今日が期限で時刻を過ぎたものは「今日」の見出しに残し、赤く強調する。「期限切れ」の見出しには昨日以前のものだけを入れる。
  - 日付が変わったら（0:00 をまたいだら）自動で並び直す。
- 作成日順のときは見出しを出さない。

**行の表示**
- チェックボックス、タイトル、タグ、期限日、追加リンクの数（例：🔗2）。
- 期限超過の行と今日が期限の行は強調する（→ 9章）。

**完了**
- チェックすると、行は取り消し線付きで約3秒残る。その間にもう一度クリックすれば元に戻る。
- 3秒たつとアーカイブへ移る。続けて完了にした行はまとめて消える。

**リンク付きのタイトル**
- 普通のクリックは行の選択だけ。
- タイトルの横に ↗ アイコンを出す。↗ のクリック、行のダブルクリック、⌘O のどれかでブラウザを開く。
- ⌘クリックは複数選択に使うので、リンクを開く操作には使わない。

**削除**
- 右クリックメニューか ⌘⌫ で、確認なしにすぐ消す。間違えたら ⌘Z で戻す。

### 4.4 詳細ペイン

- 常に表示し、⌘⌥I で隠せる。
- 何も選んでいないときは「Todo を選択してください」と薄く表示する。
- 選んだ Todo のすべての項目をその場で編集でき、自動で保存する。
- タイトル欄は ⌘Enter かフォーカスが外れたときに確定する。
- 期限日は日付ピッカーで選ぶ。横に「今日」ボタンと、期限を外す × ボタンを置く。時刻はトグルで付け外しする。
- ディスクリプションはプレーンテキスト。改行はそのまま表示し、文中の URL はクリックで開ける。一覧の行には出さない。

### 4.5 アーカイブ

- 完了日時の新しい順に並べる。
- チェックを外すと、行は未完了の見た目で約3秒残る。その間にもう一度クリックすればアーカイブに留まる。3秒たつと Inbox へ戻る。
- 完全削除：
  - 1件：右クリック →「完全に削除」、または ⌘⌫。
  - まとめて：⌘クリック・⇧クリック・⌘A で複数選び、⌘⌫ か右クリック →「選択した n 件を完全に削除」。
  - 全件：リスト上部の「アーカイブを空にする」ボタン。フィルタで絞っているときは「表示中の n 件を削除」に変わる。
  - 必ず確認ダイアログを出す（「n 件を完全に削除します。元に戻せません。」）。
- 自動では削除しない。

## 5. フィルタ

- リスト上部に条件をチップで並べ、× で外せる。
- 条件は Inbox とアーカイブで別々に持ち、どちらもアプリを閉じても保つ。

| 条件 | Inbox | アーカイブ | 内容 |
|---|---|---|---|
| タグ | ○ | ○ | 選んだタグをすべて持つ Todo（AND）。サイドバーで選ぶ |
| 期限の範囲 | ○ | － | 「期限切れ」「今日」「今週（今日から7日以内）」「期限なし」から複数選び、どれかに当てはまる Todo（OR） |
| キーワード | ○ | ○ | タイトルかディスクリプションに含まれる文字。⌘F で入力欄へ |

- 条件どうしは AND で組み合わせる。
- フィルタ中に新規追加したとき：
  - タグフィルタのタグを、新しい Todo に自動で付ける。
  - 期限は引き継がない。
  - 条件に合わない Todo も、選択を外すまでは一覧に残し、「フィルタ対象外」と小さく表示する。
- 編集して条件から外れた Todo も、選択を外すまでは一覧に残し、「フィルタ対象外」と表示する。

## 6. タグ

### 6.1 書き方

- `#` か全角の `＃` で始め、空白（半角・全角）・改行・文末までをタグ名とする。例：`#仕事` `#読書メモ` `#2026Q4`。
- `#` の直前が文頭か空白のときだけタグとみなす。`https://example.com/#top` や `C#` はタグにしない。
- URL の中の `#` はタグにしない。
- 英字の大文字・小文字は区別しない（`#Work` と `#work` は同じタグ）。表示には最初に使った書き方を使う。

### 6.2 タイトル欄での入力（X の投稿欄風）

- 入力中、`#タグ` の部分をアクセントカラーで強調する。
- `#` を打つと既存タグの候補が出る。↑↓ で選び、Tab か Enter で選択する。
- 確定したとき、`#タグ` をタイトルから取り除いてタグに移す。
  - 例：`企画書を送る #仕事 #急ぎ` → タイトル「企画書を送る」、タグ「仕事」「急ぎ」

### 6.3 タグ欄での入力

- 詳細ペインのタグ欄は1行の入力欄で、`#仕事 #読書` のように書ける。`#` を省いた空白区切り（`仕事 読書`）も受け付ける。
- 確定するとチップ表示に変わる。チップの × かバックスペースで外せる。
- 候補の出し方はタイトル欄と同じ。

### 6.4 まとめて変更・削除

- サイドバーのタグを右クリック →「名前を変更」「削除」。
- 名前の変更は、そのタグが付いたすべての Todo（アーカイブを含む）に反映する。既にある名前に変えたときは2つのタグを1つにまとめる。
- 削除は、そのタグをすべての Todo から外す。Todo 自体は消さない。
- どちらも ⌘Z で取り消せる。
- どの Todo にも使われなくなったタグは、一覧から自然に消える。

## 7. リンク

### 7.1 タイトルへの URL の自動リンク化

- タイトル全体が URL のとき：
  - その URL をタイトルのリンクにする。
  - タイトルは、いったん URL のまま保存する（入力を待たせない）。
  - 裏でページのタイトルを取得し、取れたら置き換える。取れなければドメイン名などに置き換える。
- タイトルの一部に URL が含まれるとき（例：「これ読む https://…」）：
  - URL をタイトルのリンクに抜き出し、残りの文字をタイトルにする。

### 7.2 追加リンク

- URL を貼ると、ページのタイトルを取得して表示名にする。取れなければ「ドメイン名＋URL の末尾」を表示名にする。
- 表示名はダブルクリックで書き換えられる。
- クリックでブラウザを開く。右クリックでコピー・削除ができる。

## 8. 操作の取り消し

- ⌘Z／⇧⌘Z で、取り消し・やり直しができる。
- 対象：追加・編集・タグの変更・完了・戻す・Inbox での削除・タグのまとめて変更と削除。
- 完全削除は対象外。
- 取り消しの履歴は、アプリを閉じると消える。
- 確認ダイアログは、取り消せない完全削除のときだけ出す。

## 9. デザイン

### 9.1 基本方針

- macOS 標準の見た目に沿う。独自の装飾は増やさず、余白・角丸・色の使い方でモダンに見せる。
- サイドバーは macOS 標準の半透明の背景。リストと詳細ペインはシステムの背景色。
- ライトモードとダークモードの両方に対応し、システムの設定に従う。
- 文字はシステムフォント（SF Pro、日本語はヒラギノ角ゴシック）、アイコンは SF Symbols。

### 9.2 カラー

アクセントカラーはアクセンチュアのパープル。

| 用途 | ライト | ダーク | 備考 |
|---|---|---|---|
| アクセント（ボタン・選択・リンク・チェック） | `#A100FF` | `#BE82FF` | ダーク背景では `#A100FF` だと文字が読みにくいため明るい紫にする |
| タグチップの背景 | アクセントの 12% 透過 | アクセントの 20% 透過 | 文字色はアクセント |
| 入力中の `#タグ` の強調 | `#A100FF` | `#BE82FF` | タグチップと同じ色で「タグになる」ことが分かるようにする |
| 期限超過 | システムの赤 | システムの赤 | 紫と混同しないよう、警告は赤に限る |
| 今日が期限 | システムのオレンジ | システムのオレンジ | |
| 補足情報（作成日など） | 二次テキスト色 | 二次テキスト色 | |

- 選択中の行の背景はアクセントカラー。完了チェックは紫の塗りつぶし丸に白いチェック。
- 紫は「操作できるもの・選ばれているもの」だけに使い、面を広く塗らない。

### 9.3 部品

- **リストの行**：左に丸いチェックボックス。1行目にタイトル、小さな2行目にタグ・期限日・リンクの数。行の高さは詰め気味にして一覧しやすくする。
- **タグチップ**：角丸のカプセル型で、`#仕事` の形で表示する。
- **期限超過の行**：期限日を赤字にして `exclamationmark.circle.fill` を付け、行の左端に赤い細いバーを付ける。
- **今日が期限の行**：期限日をオレンジで控えめに強調する。
- **新規入力欄**：リスト上部の角丸の入力欄。フォーカス時は紫の枠線。
- **詳細ペイン**：項目ごとにラベルと入力欄を並べたフォーム型。ディスクリプション欄は複数行で広めにとる。
- **空の状態**：Inbox・アーカイブが空のときや、フィルタで0件になったときは、中央にアイコンと短いメッセージ（「Todo はありません」「条件に合う Todo はありません」）を出す。
- **アニメーション**：完了・復帰・削除で行が消える／現れる動きを 0.2 秒ほどつける。もたつきを感じさせない長さに抑える。
- **アプリアイコン**：紫のグラデーションの角丸四角に白いチェックマーク。

## 10. キーボード操作

| キー | 動作 |
|---|---|
| ⌘N | 新規入力欄へ移る |
| ⌘Enter | 新規入力欄では追加、詳細ペインのタイトル欄では確定。Enter だけでは何もしない |
| ↑↓ | 行の選択 |
| ⌘A／⇧↑↓ | 全選択／範囲選択 |
| Space | 選択した行を完了にする／戻す（複数選択時はまとめて） |
| ⌘⌫ | Inbox では削除（確認なし、⌘Z で戻せる）。アーカイブでは完全削除（確認あり） |
| ⌘O | 選択した行のタイトルのリンクをブラウザで開く |
| ⌘⌥I | 詳細ペインの表示／非表示 |
| ⌘1／⌘2 | Inbox／アーカイブの切り替え |
| ⌘Z／⇧⌘Z | 取り消し／やり直し |
| ⌘F | キーワードフィルタの入力欄へ移る |

## 11. 作らないもの

検討した結果、次のものは作らない。

| 作らないもの | 理由 |
|---|---|
| 「今日」タブ・「期限切れ」タブ | Inbox の期限日順の見出しとフィルタで同じことができる |
| ほかのアプリから追加する入力窓（グローバルショートカット・メニューバー） | 追加はアプリのウィンドウからで足りる |
| タイトルからの日本語の日付の読み取り（「明日15時」など） | 期限日は日付ピッカーで具体的に入れる |
| 「明日」「来週」などの早押しボタン | 同上。早押しは「今日」だけ |
| Markdown・リッチテキストのディスクリプション | 実装が重く、シンプルさに合わない |
| アーカイブの自動削除 | 探したい Todo が消えているのを避ける。容量も問題にならない |
| 複数のリスト・プロジェクト | Inbox 1つだけにする |
| 同期・共有 | Mac ローカルで自分だけが使う |
