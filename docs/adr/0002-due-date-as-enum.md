# 期限日は enum で持ち、日付だけの期限は年月日で持つ

期限日は `DueDate` enum で持つ。日付だけの期限は年・月・日だけの `CalendarDay` で、時刻つきの期限は `Date` で持つ。日付だけの期限は「ある瞬間」ではなく暦の上の1日なので、`Date` で持つとタイムゾーンが変わったときに日付がずれる（東京の 11/25 0:00 は、ニューヨークでは 11/24 になる）。

## Considered Options

- `dueDate: Date?` ＋ `hasDueTime: Bool`（初期の設計案）：日付だけの期限も `Date` で持つので、上のずれが起きる。「期限なしなのに時刻つき」というありえない状態も作れてしまう。
- 上の形で、日付だけのときは正午を保存する：数時間のずれなら日付が変わらないが、ずれを小さくしているだけで、なくしてはいない。
- `DateComponents` で年月日を持つ：時・分・タイムゾーンなど年月日以外も入れられ、比較の機能もない。

## Consequences

保存する JSON の形がこの enum で決まる。あとで形を変えると、保存済みのデータを読み替える処理が要る。
