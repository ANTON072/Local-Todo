# ドキュメントだけで済む作業は、ドキュメントだけの PR で出してよい

ADR-0006 の「ドキュメントだけの PR は出さない」をやめる。PRD の書き方の整理（#56）のように、作業そのものがドキュメントだけで終わるものがあり、それを関係のない Issue の実装 PR に混ぜると、レビューの範囲がぼやけ、実装のマージも待たされるため。

Issue を詰めたときに書いた ADR・CONTEXT.md・TODO.md の変更は、これまでどおりその Issue の実装 PR に入れる。test-writer が決めたことを読めるよう、実装より先にコミットする必要がある、という ADR-0006 の理由は変わらないため。
