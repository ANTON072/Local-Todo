# 作らない機能を決めておく

検討した結果、次の機能は作らない。同じ要望がまた出たときに、なぜ作らないと決めたかを見直せるよう残す。作ることにしたときは、新しい ADR でこの ADR を置き換える。

| 作らないもの | 理由 |
|---|---|
| 「今日」タブ・「期限切れ」タブ | Inbox の期限日順の見出しとフィルタで同じことができる |
| ほかのアプリから追加する入力窓（グローバルショートカット・メニューバー） | 追加はアプリのウィンドウからで足りる |
| タイトルからの日本語の日付の読み取り（「明日15時」など） | 期限日はカレンダーで具体的に入れる |
| 「今日」「明日」「来週」などの早押しボタン | 同上 |
| Markdown・リッチテキストのディスクリプション | 実装が重く、シンプルさに合わない |
| アーカイブの自動削除 | 探したい Todo が消えているのを避ける。容量も問題にならない |
| 複数のリスト・プロジェクト | Inbox 1つだけにする |
| 同期・共有 | Mac ローカルで自分だけが使う |
