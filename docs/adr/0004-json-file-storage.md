# 保存は DB を使わず、JSON ファイル1つにする

Todo の全件を JSON ファイル1つ（`todos.json`）に保存する。起動時に全件をメモリに読み込み、以降はメモリ上のデータを正として、絞り込みも並び替えもメモリ上で行う作りなので、DB が得意な部分的な書き込みや問い合わせを使う場面がない。数千件でもファイルは 1MB ほどで、変更のたびに全体を書き直しても一瞬で終わる。

## Considered Options

- SQLite（外部ライブラリを使わない決まりなので C の API を直接使う）：タグや追加リンクの配列を別のテーブルに分けるか JSON の列に入れる必要があり、形を変えるたびにマイグレーションが要る。バックアップもファイルのコピーで済まない（WAL のファイルも絡む）。読み書きのコードも数倍になる。
- SwiftData：タグの配列での絞り込み（`#Predicate`）が扱いにくい。データを持つのが自前の TodoStore と SwiftData の両方になり、役割がぶつかる。

## Consequences

件数が何万件にもなると、毎回の全体の書き直しが重くなる。そのときは SQLite に移すことを考える。保存は `Persistence` の中に閉じているので、差し替えはその中で済む。
